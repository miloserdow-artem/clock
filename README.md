# Clock — аналоговые часы

Учебный проект, созданный 16 января 2022 года. Представляет собой аналоговые часы на чистом JavaScript с использованием CSS‑трансформаций для плавного вращения стрелок.

Это небольшой, но наглядный проект для практики работы с DOM-деревом, временными интервалами и CSS‑свойствами анимации.

**Дата создания:** 16 января 2022 года

## Функционал
- **Реальное время:** Отображение текущего системного времени в реальном времени.
- **Плавная анимация:** Плавное вращение часовой, минутной и секундной стрелок.
- **Динамическое обновление:** Позиция стрелок пересчитывается и обновляется каждую секунду через `setInterval`.

## Технологии
- HTML5
- CSS3 (Трансформации `transform`, абсолютное позиционирование)
- Чистый JavaScript (Vanilla JS)

## Как это работает
Каждую секунду создаётся объект `Date`, из которого извлекаются текущие значения часов, минут и секунд. Эти значения переводятся в градусы поворота:
- **Часовая стрелка:** Поворачивается на 30° за один час (с динамической поправкой на прошедшие минуты).
- **Минутная и секундная стрелки:** Поворачиваются на 6° за каждую единицу времени.

Финальный поворот применяется к элементам интерфейса через CSS-свойство `transform: rotateZ()`.
