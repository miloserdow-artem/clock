# Clock — аналоговые часы
Учебный проект, созданный 16 января 2022 года. Аналоговые часы на чистом JavaScript с использованием CSS‑трансформаций для вращения стрелок.

## Функционал
- Отображение текущего времени в реальном времени;
- Алавное вращение часовой, минутной и секундной стрелок;
- Обновление позиции стрелок каждую секунду через setInterval.
## Технологии
- HTML5
- CSS3 (трансформации, позиционирование)
- JavaScript
## Как это работает
Каждая секунда создаётся объект Date, из которого извлекаются часы, минуты и секунды. Значения переводятся в градусы поворота: часовая стрелка — 30° в час (с поправкой на минуты), минутная и секундная — по 6° на единицу. Поворот применяется через transform: rotateZ().
